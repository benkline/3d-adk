# Example: Desk Cable Organizer

A practical desktop cable organizer that keeps charging cables and cords neatly organized and easily accessible.

## Design Brief

This example demonstrates a multi-feature design with organizing compartments.

**Objective:** Create a cable organizer that:
- Holds 4-6 cables/charging ports
- Keeps them organized by type (USB, Lightning, USB-C)
- Prevents tangling
- Stays compact on desk surface
- Allows easy cable insertion/removal

**Materials:** PETG (more durable than PLA)
**Print Time:** ~4.5 hours
**Weight:** ~85g

## Modeling Phase Output

The Modeling Agent generates:

- **project.scad** - Parametric OpenSCAD with configurable slots
- **model.stl** - Ready-to-print STL file
- **model.3mf** - Alternative format
- **printability_analysis.json** - Notes on tree supports and optimal orientation
- **optimization_recommendations.json** - Print settings for PETG

## Printing

- **Material:** PETG (more durable than PLA)
- **Nozzle:** 235°C
- **Bed:** 80°C
- **Supports:** Tree supports recommended
- **Infill:** 15%
- **Print time:** ~4.5 hours

## Quality Results

Expected output:
- ✓ Functional cable slots
- ✓ Smooth surfaces for cable insertion
- ✓ Stable base with proper supports
- ✓ Minimal support scarring

## Post-Processing

1. Carefully remove tree supports
2. Light sanding of contact surfaces
3. Add rubber feet to bottom corners
4. Optional: Paint or stain for aesthetics
